# Learning

Photographs of the paper system in use. Not documentation — evidence. The method documents say how it should work; this folder shows what actually happened, so the next review can be argued from the artefacts instead of from memory.

Naming: `YYYYMMDD_what.jpg`. The photographs themselves stay **local** — `learning/` is gitignored, only this index is tracked — so the folder can hold site photos without them landing in a public repository.

| File | Artefact | What it shows |
|---|---|---|

| `20261122_fromWhiteboard.jpg` | Kick-off grid, transcribed from the Friday board | one line per person; several rows carry two commitments in one cell |
| `20261123_whiteboard.jpg` | Whiteboard, Monday of week 48 | PTW appears four times — the critical path behind all three goals, and the thing the OPEN sheet missed |
| `20261123_kickoff_grid.jpg` | Kick-off grid, Monday 23.11 | first dated grid with `TODAY'S 3` filled; 12 people, five `✓` |
