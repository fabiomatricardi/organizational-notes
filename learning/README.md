# Learning

Photographs of the paper system in use. Not documentation — evidence. The method documents say how it should work; this folder shows what actually happened, so the next review can be argued from the sheets instead of from memory.

Naming: `YYYYMMDD_what.jpg`. The photographs themselves stay **local** — `learning/` is gitignored, only this index is tracked — so the folder can hold site photos without them landing in a public repository.

| File | What it is | What it shows |
|---|---|---|
| `20261122_targets.jpg` | A4 OPEN sheet for week 48, written before the week started | 11 commitments, 11 owners, 11 dates — but no PTW line, and both people columns empty |
| `20261122_fromWhiteboard.jpg` | Kick-off grid, transcribed from the Friday board | one line per person; several rows carry two commitments in one cell |
| `20261123_whiteboard.jpg` | Monday board, week 48, organised by area (LQ/ICSS, FIR, AIR) | PTW appears four times — the critical path behind all three goals, and the thing the sheet missed |

The review of these three is in the week-48 session notes; the method documents that came out of it are [`docs/00-how-it-works.md`](../docs/00-how-it-works.md) (page 2, "Three questions, answered") and [`docs/01-method.md`](../docs/01-method.md).
